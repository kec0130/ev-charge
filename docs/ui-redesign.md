# 선택 시안 기반 UI 개선

2026-09-14. UI 작업 전 상태는 `ffca570` 커밋으로 보존했습니다.

## 적용 기준

`selected_designs`의 지도, 블로그 목록·상세, 중고시세 시안의 배치를 사용했습니다. 내비게이션의 밑줄은 없애고, 급속·완속 마커 색상을 구분했습니다. 로고는 사용자가 첨부한 시안에 맞춰 검은색 ‘전기차’와 번개 없는 노란색 ‘G’로 적용했습니다. 선택 시안 파일은 수정하지 않았습니다.

## 동작

- 공통: PC 상단 내비게이션, 모바일 하단 탭, 새 로고와 SVG 파비콘, 키보드 포커스와 본문 바로가기.
- 지도: PC 좌측 목록·우측 지도, 모바일 접기·펼치기 목록, 주소 검색과 지역 선택, 공개 여부·충전 가능·급속 필터, 거리·가능 대수 정렬, 길찾기와 상세·리뷰.
- 마커: 이용 가능한 급속이 있으면 진한 초록, 완속만 남으면 연한 초록, 이용 불가·유형 미확인은 회색. 혼합 충전소도 잔여 급속을 먼저 판단합니다. 급속 필터를 켜면 급속 대수만 마커에 반영합니다.
- 도심에서 숫자가 겹치는 것을 줄이기 위해 일부 마커의 숫자 라벨만 생략합니다. 충전소 핀 자체는 유지하며, 선택한 충전소의 라벨은 항상 표시합니다.
- 모바일에서는 지도와 목록이 각각 공간을 갖습니다. 충전소를 선택하면 줄어든 지도 영역의 중심에 선택한 마커를 표시합니다.
- 블로그: 기존 MDX 글의 검색·카테고리·페이지 이동, 요약과 읽기 시간, 실제 본문 제목에 연결된 목차, 관련 글과 지도 링크.
- 중고시세: 기존 데이터의 카드 보기, 검색·정렬·월 변경, 조사 시점과 과거 자료 안내. 예시 시세나 새 글은 추가하지 않았습니다.
- 광고: 기존 광고 슬롯을 블로그 보조 영역·MDX 본문·중고시세 하단에 연결했습니다.

## 모바일 지도 공간 개선

- 지도 페이지의 모바일 헤더는 52px, 하단 탭은 60px로 줄이고, 지역 선택은 로고 옆 버튼으로 옮겼습니다. 주소 입력은 16px로 유지합니다.
- 처음에는 충전소 목록을 64px 요약 막대로 접습니다. 마커를 누르면 목록 미리보기가 열리며, 목록 버튼이나 손잡이를 위아래로 밀어 접기·미리보기·펼치기를 전환합니다. 지도 아이콘을 누르면 다시 접습니다.
- 지도 영역은 브라우저의 동적 화면 높이와 실제 검색 영역 높이에 맞춰 배치합니다. 목록이 지도나 현재 위치 버튼을 덮지 않습니다. 지도 크기 갱신은 다음 프레임에 실행해 WebKit의 ResizeObserver 반복 오류를 방지합니다.
- 390×680 화면에서 기본 지도 높이가 약 173px에서 410px로 늘었습니다. Chrome·WebKit에서 지역 선택, 같은 마커 재선택, 상세보기, 목록 전환, 320·390·430px 및 가로 화면 배치를 확인했습니다. 실제 iPhone 기기 검증은 포함하지 않습니다.
- Chrome의 터치 이벤트로 손잡이를 위아래로 미는 동작을 확인했습니다. 린트·타입 검사·기존 테스트 18개와 캐시 없는 Node 22 배포 빌드(25개 페이지)가 통과했습니다.

### 목록을 접은 뒤 지도에 빈 공간이 남는 문제

- 재현: 목록 펼치기 → 접기를 실행하면 바깥 지도 영역은 574px로 복구되지만, SDK 지도 요소는 76px에 고정됐습니다. `setSize`가 지도 요소에 픽셀 크기를 직접 지정하므로 그 요소를 관찰하면 이후 부모 영역의 크기 변화를 감지하지 못했습니다.
- 수정: SDK 지도 요소 대신 레이아웃을 담당하는 부모 `.map-region`을 관찰하고 그 크기로 지도를 갱신합니다. 다음 프레임 처리와 동일 크기 확인은 유지합니다.
- 확인: Chrome·WebKit에서 3회 연속 펼치기·접기, 손잡이 이동, 화면 높이 변경, 가로·세로 전환, PC 전환 후 모바일 복귀를 실행했습니다. 바깥 영역뿐 아니라 실제 SDK 요소와 내부 지도 레이어의 너비·높이가 일치하는지 검사했고, 반복 접기 후 화면 캡처에서 지도 전체가 채워진 것을 확인했습니다. 린트·타입 검사도 통과했습니다.
