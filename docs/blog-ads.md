# 블로그 광고 배치

모든 글의 공통 상세 화면에 기존 본문형 애드센스 슬롯 `8995781868`을 두 번 표시합니다.

- 상단: ‘이 글에서 알아볼 내용’ 요약 바로 아래. 모바일 목차보다 앞입니다.
- 하단: ‘블로그 목록으로’ 링크 바로 위. 모바일 충전 지도 안내 카드보다 뒤입니다.
- MDX 안에 직접 넣은 `<AdSense />`는 유지합니다. 따라서 수동 광고가 있는 글은 공통 광고 두 개에 본문 광고가 추가됩니다. 새 글에 공통 광고를 넣기 위해 MDX를 수정할 필요는 없습니다.

광고에는 작은 ‘광고’ 표시, 위아래 구분선과 여백을 적용합니다. 모바일에서도 본문 너비에 맞추고, 초기 광고 영역은 최소 160px을 확보합니다. 실제 광고 높이는 애드센스가 결정합니다. 광고 없음(`data-ad-status="unfilled"`) 응답이나 요청 오류가 발생하면 해당 광고 영역을 접습니다.

실제 광고 요청은 프로덕션 환경에서 `NEXT_PUBLIC_GOOGLE_ADS_CLIENT_ID`가 설정되어 있고, 광고 영역 너비가 250px 이상일 때 실행합니다. 개발 환경에서는 광고 자리만 확인할 수 있습니다. 실제 광고 표시 여부는 애드센스 응답과 브라우저의 광고 차단 여부에 따라 달라집니다.

글을 이동하면 해당 글의 광고 요소를 새로 생성합니다. 같은 글에서 목차 강조나 화면 크기가 바뀔 때는 중복 요청하지 않습니다. Contentlayer의 MDX globals 객체를 고정해 본문 광고도 목차 상태 변경으로 다시 생성되지 않게 했습니다.

참고: [본문형 광고 크기와 간격](https://support.google.com/adsense/answer/9190051?hl=ko), [모바일 전체 너비 확장 설정](https://support.google.com/adsense/answer/9189961?hl=ko).

## 검증

- Node 22 프로덕션 빌드와 린트·타입 검사 통과. 생성된 14개 글 모두에 상단·하단 광고가 각각 한 개씩 포함됩니다.
- Chrome·WebKit의 320·390·768·1440px 화면에서 배치, 본문과 같은 너비, 가로 넘침 없음 확인.
- 광고 응답을 테스트 코드로 대체해 실제 노출 없이 검증했습니다. 목차 상태 변경과 화면 크기 변경 시 중복 요청이 없고, 다른 글 이동 및 뒤로 가기에서는 새 광고를 요청합니다.
- 광고 없음 응답 및 요청 오류 시 광고 영역이 접히고 본문은 계속 표시됩니다. 실제 광고 소재와 수익은 이 테스트의 검증 대상이 아닙니다.
