# 행정구역 변경과 충전소 검색

확인일: 2026-09-15

## 적용 범위와 근거

전남광주통합특별시(시도 코드 `12`)의 27개 시·군·구와 전북특별자치도(`52`)의 14개 시·군 코드를 반영했습니다.

- [행정안전부 2026.7.1. 행정기관·법정동 변경 안내](https://www.mois.go.kr/frt/bbs/type001/commonSelectBoardArticle.do?bbsId=BBSMSTR_000000000052&nttId=127039)
- 위 공지의 [jscode20260701.zip 원본](https://www.mois.go.kr/cmm/fms/FileDown.do?atchFileId=FILE_00146280tlU2Y2B&fileSn=0)에 포함된 `KIKcd_B.20260701` 텍스트에서 시·군·구 코드를 확인했습니다. 전북 코드도 같은 자료와 대조했습니다.
- 네이버 지도 SDK의 정방향·역방향 주소 변환과 한국환경공단 `getChargerInfo`를 실제 호출해 새 명칭·코드가 사용되고 있음을 확인했습니다. 통합 지역의 27개 코드 모두 정상 응답과 충전소 데이터가 있었습니다.

| 지역 | 이전 코드 | 현재 코드 |
| --- | --- | --- |
| 광주 동구 | 29110 | 12210 |
| 광주 광산구 | 29200 | 12330 |
| 목포시 | 46110 | 12110 |
| 광양시 | 46230 | 12190 |
| 고흥군 | 46770 | 12740 |
| 전주시 | 45110 | 52110 |

시도 접두사만 바꾸면 광양시·고흥군 등의 코드가 잘못되므로, 이전 코드와 현재 코드를 일대일로 연결합니다.

## 검색 동작

- 지역 선택에는 전남광주통합특별시를 하나의 시도로 표시하고 27개 시·군·구를 제공합니다. 모바일 헤더에서는 `전남광주 동구`처럼 줄여 표시합니다.
- 현재 위치와 지도 이동 시 네이버가 반환한 10자리 법정동/행정동 코드에서 해당 시·군·구를 확인합니다. 이름을 사용할 때는 시도와 시·군·구를 함께 비교합니다. 알 수 없는 시도에서 `동구`라는 이름만 보고 부산 동구를 선택하던 처리를 제거했습니다.
- 전주시 완산구처럼 충전소 API가 상위 시 단위로 조회하는 지역은 전주시 코드로 연결합니다. 경기도 광주시는 별도 지역으로 유지합니다.
- 예전 주소 입력은 네이버 주소 검색을 거쳐 새 코드로 연결합니다. 예전 코드를 사용하는 `/api/chargers` 호출도 서버에서 현재 코드로 변환합니다. 실제 API 조회에서 폐지된 광주·전남·전북 코드는 빈 결과를 반환했습니다.
- 지역 선택으로 지도 좌표를 찾지 못했을 때는 충전소 조회 지역만 먼저 바뀌지 않도록 했습니다.

코드 목록은 `src/constants/chargerCode.ts`, 이전 코드 연결은 `src/constants/regionAliases.ts`, 역방향 주소 판별은 `src/utils/regions.ts`에 있습니다.

## 검증

- 기존 테스트를 포함한 25개 테스트, 린트, 타입 검사 통과.
- 새 코드와 이전 코드, 명칭 별칭, 여러 시도의 동구, 경기도 광주시, 전주시의 일반구 처리 회귀 테스트를 추가했습니다.
- Chrome·WebKit에서 실제 광주 동구 좌표의 현재 위치 조회, 새 명칭과 이전 명칭으로 주소 검색, 목포·신안 지역 선택, 전주·경기도 광주시 검색을 확인했습니다. 목록을 반복해서 접은 뒤에도 지도 내부 크기가 복원됩니다.
- 캐시 없는 Node 22 환경에서 배포 빌드가 통과했고 25개 페이지를 생성했습니다.
- 충전소 API의 전체 조회 및 기존 필터를 그대로 사용합니다. 테스트에서 확인한 원본 데이터 수와 화면의 공개 충전소 수는 필터와 조회 시점에 따라 다릅니다.
