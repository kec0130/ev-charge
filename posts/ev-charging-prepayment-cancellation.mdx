## 문자보다 먼저 볼 취소 내역

전기차 충전이 끝났는데 처음 결제된 금액이 그대로 남아 있거나 승인 문자가 한 번 더 오면 이중결제가 아닌지 걱정될 수 있습니다. 이때는 **처음 승인한 금액, 그 승인에 연결된 취소 금액, 실제 충전 요금**을 함께 확인해야 합니다. 선결제 뒤 남은 금액을 부분취소하는 방식도 있어서, 처음 금액이 통째로 취소되어야만 정상인 것은 아닙니다.

반대로 충전이 실패했는데 승인만 남았거나, 사업자가 안내한 시간이 지난 뒤에도 취소 여부를 확인할 수 없다면 해당 거래를 특정해 문의하는 편이 좋습니다. 승인 문자가 두 개라는 이유만으로 이중청구를 확정할 수도, 선결제라는 이유로 모두 정상이라고 넘길 수도 없겠죠.

아래는 2026년 9월 23일 확인한 공식 FAQ와 사업자 답변을 참고해, 카드 선결제 거래를 확인할 때 필요한 항목을 정리한 안내입니다. 아이파킹EV의 일반 처리 방식과 다른 사업자의 개별 처리 사례는 구분해서 설명하겠습니다.

## 승인 건별 확인 순서

먼저 카드사 앱이나 이용명세에서 해당 충전 거래의 상세 내역을 열어보세요. 앱마다 메뉴 이름은 다르지만, 볼 것은 결제 알림의 개수가 아니라 **각 승인 건에 취소가 반영됐는지**입니다. 충전을 여러 번 시도했다면 실패한 시도와 실제 충전된 시도를 따로 나누어야 빠진 거래를 찾기 쉽습니다.

1. 충전한 날짜와 시간으로 승인 내역을 찾고, 가맹점명·승인 금액·승인번호를 기록합니다. 같은 날 같은 금액이라도 서로 다른 시도의 승인일 수 있습니다.
2. 각 승인 거래에 연결된 전체취소 또는 부분취소 내역을 확인합니다. 앱에서 찾기 어렵다면 카드사에 해당 승인번호로 취소 반영 여부를 물어보세요. 취소 문자가 없다는 것과 실제 취소가 안 됐다는 것은 구분해서 봅니다.
3. 충전사업자의 이용 내역이나 영수증에 나온 충전 요금과 카드에 남은 결제 금액을 대조합니다. 충전기에서 오류가 났다면 실제 충전이 진행됐는지도 함께 확인합니다.
4. 맞지 않는 승인 건이 있으면 그 건을 지정해 문의합니다. ‘두 번 결제됐어요’보다 어느 승인에 취소가 없고 실제 충전 요금은 얼마인지 설명하는 편이 명확합니다.

| 확인한 상황 | 먼저 대조할 기록 | 다음 확인 |
| --- | --- | --- |
| 처음 선결제 금액 일부만 취소됨 | 남은 결제 금액과 실제 충전 요금 | 해당 사업자가 부분취소 방식인지 확인 |
| 선결제와 별도 승인이 모두 남아 있음 | 각 승인에 연결된 취소 내역과 충전 영수증 | 최초 승인도 최종 청구로 남는지 사업자에 확인 |
| 충전 실패 후 승인만 남아 있음 | 실패 시각·기기 번호와 해당 승인 | 사업자에 충전 여부와 취소 처리 상태 확인 |

여러 번 재시도한 뒤라면 한 건이 취소됐다고 다른 승인까지 모두 정리됐다고 생각하지 않는 편이 좋겠습니다. 확인되지 않은 결제를 해결하려고 같은 충전을 반복 결제하기보다, 먼저 남아 있는 거래를 정리해보세요.

## 부분취소와 실제 누락의 차이

[아이파킹EV 공식 FAQ](https://www.iparkingev.co.kr/kr/customer/faq.php)의 ‘타사(로밍) 회원 및 비회원 충전 서비스 이용 방법은?’에는 비회원이 화면 안내에 따라 선결제한 뒤 충전하고, 종료 시 실제 충전 요금을 제외한 나머지를 자동 부분취소한다고 나옵니다. 카드사 확인에는 **1~2일**이 걸린다고 안내합니다.

이 방식이라면 처음 승인 금액 전체의 취소만 찾을 것이 아니라, 실제 충전 요금을 남긴 부분취소가 있는지 봐야 합니다. 다만 이 기간은 아이파킹EV의 해당 안내입니다. 다른 충전사업자의 처리 시간까지 같다고 볼 수는 없으니, 이용한 사업자의 FAQ나 고객센터 안내를 기준으로 확인하세요.

실제 취소 누락을 확인하고 처리한 사례도 있습니다. [씨어스의 공개 고객 문의와 답변](https://www.cus21.co.kr/qna/?q=YToxOntzOjEyOiJrZXl3b3JkX3R5cGUiO3M6MzoiYWxsIjt9&bmode=view&idx=171624590&t=board)을 보면, 2026년 6월 4일 선결제 후 다시 결제됐다는 문의에 대해 6월 8일 관리자가 최초 결제의 미환불을 확인하고 환불 처리했다고 답했습니다.

이 사례만으로 같은 증상의 원인을 모두 알 수는 없습니다. 다만 ‘선결제는 나중에 알아서 정리된다’는 설명만 듣고 계속 기다리기보다, 취소가 확인되지 않는 거래는 실제 처리 상태를 물어볼 필요가 있다는 점은 분명해 보입니다.

## 문의할 곳과 준비할 정보

문의처는 충전소가 있는 건물 이름보다 **어느 서비스로 결제했는지**를 기준으로 찾으면 됩니다. 충전기에서 비회원으로 직접 결제했다면 현장에 적힌 운영사와 고객센터를 확인하세요. 다른 회사 회원카드로 로밍 이용했다면 카드 발급 서비스의 내역도 봐야 합니다. 아이파킹EV FAQ도 제휴회원의 결제·충전 내역은 이용한 로밍사를 통해 확인하도록 안내합니다.

전화하기 전에는 충전소 이름과 기기 번호, 이용 시각, 인증·결제 방식, 실제 충전 여부와 요금, 취소가 확인되지 않는 승인 건을 한곳에 모아두면 좋습니다. 사업자가 충전 기록을 찾을 정보와 카드 거래를 찾을 정보를 함께 준비하는 것이죠. 화면에 오류 문구가 남아 있다면 그 내용도 기록하되, 고객센터가 요청하지 않은 민감정보까지 공개할 필요는 없습니다.

예를 들어 이렇게 설명할 수 있습니다.

> 해당 충전기에서 결제한 뒤 충전이 시작되지 않았습니다. 같은 시간대 승인 중 한 건은 취소됐고, 다른 한 건은 취소 내역이 보이지 않습니다. 실제 충전 기록과 남아 있는 승인의 취소 처리 여부를 확인해주세요.

충전이 정상적으로 끝났다면 상황을 다르게 설명해야겠죠. ‘충전은 정상 종료됐는데 선결제와 별도 승인이 함께 남아 있습니다. 영수증의 충전 요금과 각 승인의 취소 처리 상태를 확인해주세요’처럼 실제 내역에 맞춰 문의하면 됩니다.

한국자동차환경협회가 담당한 [충전 실패 후 결제취소 문의 사례](https://www.aea.or.kr/help/qnaView.do?idx=43727)에서도 운영자가 해당 결제 내역의 취소를 확인하고 추가 문의는 전기차 헬프데스크 1661-9408로 안내했습니다. 2023년의 개별 사례이며, 이 번호를 모든 민간 충전사업자의 공통 환불 창구로 생각하면 안 됩니다. 먼저 이용한 충전기의 운영사와 결제 서비스를 확인하세요.

승인번호나 거래 내역은 확인된 공식 상담 경로로 전달하고, 공개 게시판에 카드번호 전체·CVC·비밀번호·인증번호를 올리지 마세요. 화면을 첨부할 때도 관계없는 거래와 개인정보는 가리는 편이 좋습니다.

## 처리됐다는 답변을 받은 뒤

사업자에게 취소 처리됐다는 답변을 받았다면 **어느 승인 건을 언제, 얼마만큼 취소했는지**를 확인해두세요. 전체취소인지 부분취소인지 알아야 카드 내역에서 같은 거래를 다시 찾을 수 있습니다. 안내받은 반영 시점에도 표시가 맞지 않으면 그 처리 정보를 가지고 카드사에 취소 접수와 반영 상태를 확인하면 됩니다.

확인이 끝났는지는 문자가 새로 왔는지보다, 실제 충전한 건의 최종 금액이 영수증과 맞고 취소 대상 승인도 각각 정리됐는지로 보는 편이 좋겠습니다. 충전 요금은 맞는데 적용 단가 자체가 예상과 달랐다면 별개의 문제입니다. 그때는 [회원카드별 로밍 요금 확인 방법](/blog/ev-charging-roaming-card-rates)에서 운영사와 사용 카드의 조합부터 확인해보세요.
